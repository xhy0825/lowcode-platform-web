# 低代码平台部署指南

## 项目结构

### 前端 (lowcode-platform-web)
- Vue 3.4 + TypeScript + Element Plus + Vite
- 已构建成功，产物位于 `dist/` 目录

### 后端 (lowcode-platform-server)
- Spring Cloud Alibaba 微服务架构
- 包含以下服务模块：
  - Gateway (API网关)
  - System Service (系统管理服务)
  - Data Service (数据引擎服务)
  - Form Service (表单服务)
  - Flow Service (流程服务)
  - Page Service (页面服务)
  - Report Service (报表服务)
  - File Service (文件服务)

## 部署前准备

### 1. 安装中间件

#### MySQL 8.x
```bash
# 创建数据库
CREATE DATABASE lowcode_platform CHARACTER SET utf8mb4;

# 执行SQL脚本
mysql -u root -p lowcode_platform < sql/01_sys_common.sql
mysql -u root -p lowcode_platform < sql/02_tenant_template.sql
mysql -u root -p lowcode_platform < sql/03_business_tables.sql
```

#### Redis 7.x
```bash
redis-server
```

#### Nacos 2.3.x
```bash
# 启动Nacos (单机模式)
sh startup.sh -m standalone
```

#### RocketMQ 5.x (可选，用于流程通知)
```bash
# 启动NameServer
mqnamesrv

# 启动Broker
mqbroker -n localhost:9876
```

### 2. 配置各服务

修改各服务的 `application.yml`:
- MySQL连接地址
- Redis地址
- Nacos地址

## 启动顺序

1. **启动中间件** (MySQL, Redis, Nacos)
2. **启动Gateway** (端口8080)
3. **启动System Service** (端口8081)
4. **启动Data Service** (端口8082)
5. **启动Form Service** (端口8083)
6. **启动Flow Service** (端口8085)
7. **启动前端** (npm run dev 或 部署dist目录)

## 技术特性

### 多租户架构
- Schema隔离模式
- TenantContextHolder动态切换数据源
- 请求头/子域名识别租户

### 权限控制
- RBAC权限模型
- 数据权限范围控制 (全部/本部门/本部门及子部门/仅本人)
- 权限注解 + 数据权限拦截器

### 安全机制
- Groovy脚本白名单安全沙箱
- JWT认证
- API权限校验

### 动态建表
- 数据模型设计 → DDL生成 → 物理表创建
- 字段类型映射 (前端类型 → MySQL类型)
